# 2026-07-28 作業メモ

## 認知モデル制御の理由を整理

生徒AIを認知モデルで制御する理由を、「生徒を教育するため」ではなく「教室全体を見るため」として整理した。

追加ファイル:

- `docs/classroom_level_cognitive_model_rationale.md`

整理した主張:

- 本研究の目的は、1人の生徒AIを教育することではない
- 目的は、教師1人が複数生徒を見て授業を行う教室場面をシミュレーションすること
- そのためには、生徒AI集団の理解度・誤概念・個人特徴を分布として制御できる必要がある
- 認知モデルは、クラス全体の条件を設計するための制御層である
- 教師AIや講義設計AIは、観察可能な反応からクラス状態を把握し、授業方針を変える

発表で使う説明:

> 生徒AIを認知モデルで制御するのは、個々の生徒を教育するためではなく、教師AIが教室全体を見て授業方針を変えられるかを検証するためである。
