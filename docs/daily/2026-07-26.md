# 2026-07-26 作業メモ

## 生徒AI発表用Notebookの追加

進捗報告で使いやすいように、生徒AI設計の発表用Notebookを追加した。

追加ファイル:

- `notebooks/student_ai_presentation_experiment.ipynb`

目的:

- 認知モデル中心の設計として説明できるようにする
- 発表で使う式、グラフ、テスト結果、性格別発話を1つのNotebookにまとめる
- 既存の詳細Notebookは補助実験として扱い、発表用Notebookは本編だけを上に集める

Notebookの構成:

1. Setup
2. 発表での主張
3. 認知モデルの式
4. 発表用実験の実行
5. 理解度とテスト結果
6. 難易度・誤概念・スキル弱点
7. 性格別発話サンプル
8. 複数生徒AIにしたときの分布
9. 発表で使うまとめ
10. 補助実験として従来モデルとBKT/IRT寄りモデルの比較

発表での見せ方:

- 式: 認知モデルのセルをそのまま使う
- グラフ: 学習曲線、認知要因別グラフ、性格別発話特徴、複数生徒分布を使う
- 補助: 従来モデル比較は、時間がある場合だけ使う

## 発表用Notebookの拡張

`notebooks/student_ai_presentation_experiment.ipynb` を発表向けに追加調整した。

変更内容:

- 発表用テストを20問から100問へ拡張
  - 元の20問テストは変更しない
  - Notebook内で20問を5セットに複製し、発表用100問テストを作る
- 30人分の生徒AIパラメータ設計セルを追加
  - 総合理解度、弱点スキル、自己効力感、質問傾向、意欲、誤概念を分布として設計
  - 保存済みの20人生徒データは壊さず、発表用にメモリ上で30人分を生成
- 30人クラスの予測正答率セルを追加
  - 30人 × 100問で、クラス全体の予測正答率分布を可視化
  - 個人ごとの正答確率、スキル別弱点、難易度別の影響をグラフ化

発表での説明:

- 複数生徒AIにしても正答確率の式は変わらない
- 変わるのは、生徒ごとのパラメータ分布
- その分布により、クラス平均、低理解層、弱点スキル、個別支援対象が見えるようになる
