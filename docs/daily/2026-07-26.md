# 2026-07-26 作業メモ

## 生徒AI発表用Notebookの追加

進捗報告で使いやすいように、生徒AI設計の発表用Notebookを追加した。

追加ファイル:

- `notebooks/student_ai_presentation_experiment.ipynb`

目的:

- 認知モデル中心の設計として説明できるようにする
- 発表で使う式、グラフ、テスト結果、性格別発話を1つのNotebookにまとめる
- 既存の詳細Notebookは補助実験として扱い、発表用Notebookは本編だけを上に集める

Notebookの構成:

1. Setup
2. 発表での主張
3. 認知モデルの式
4. 発表用実験の実行
5. 理解度とテスト結果
6. 難易度・誤概念・スキル弱点
7. 性格別発話サンプル
8. 複数生徒AIにしたときの分布
9. 発表で使うまとめ
10. 補助実験として従来モデルとBKT/IRT寄りモデルの比較

発表での見せ方:

- 式: 認知モデルのセルをそのまま使う
- グラフ: 学習曲線、認知要因別グラフ、性格別発話特徴、複数生徒分布を使う
- 補助: 従来モデル比較は、時間がある場合だけ使う
