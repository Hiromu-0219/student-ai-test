# 研究の全体像

最終更新: 2026-10-01 JST

目的は、複数生徒のクラスを観察し、教師が授業構成と個別支援を調整できる教育シミュレーションを作ることです。

## 中心となる流れ

生徒の内部状態 → 認知・行動モデル → 生徒発話 → 観察情報 → 伝達AI → 教師の推定状態 → 授業設計・教師発話 → 次の生徒反応

認知モデルは正答確率と回答、行動モデルは授業中の行動、性格は表現の差を制御します。LLMはその条件に沿って発話を生成します。BKT/IRT寄りの認知モデルはシミュレーション用の近似であり、実生徒データで推定したものではありません。

生徒の内部状態は評価用の正解データとして保持し、伝達AIと教師には観察可能な情報と過去の観察履歴を渡します。

## 評価すること

1. 生徒制御の一貫性: 認知モデルの回答と生成発話・採点の一致。
2. 伝達AIの推定: 観察から推定した状態と評価用内部状態の一致。
3. 授業設計の適応: クラス条件に応じた対象スキル、進度、支援対象の変化。
4. 実行の安定性: 人数・乱数seed・LLM条件を変えた再現性と実行時間。

現在の検証範囲は制御可能性と内部整合性です。人間生徒との一致や教育効果、授業の最適性を証明するには、実データや独立した評価が必要です。

`UPDATE_STUDENT_KNOWLEDGE=False` では、生徒の学習効果ではなく観察と教師側の推定・授業設計の変化を検証します。

## 次の優先事項

1. 小規模クラスでLLMを含む一連の流れと会話ログを安定させる。
2. 異なるクラス条件で授業設計が変わるか比較する。
3. 複数seedで指標を集計し、論文用の表と図を作る。

当面は単元拡張や新しいAIの追加より、この比較実験を優先します。
