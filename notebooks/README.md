# Notebook案内

最終更新: 2026-10-01 JST

通常はこの3つを使用します。

| Notebook | 目的 |
| --- | --- |
| `simulation_timeline_experiment.ipynb` | 授業シミュレーションと時系列ログ |
| `communication_ai_rq1_experiment.ipynb` | 伝達AIの推定評価 |
| `student_ai_presentation_experiment.ipynb` | 生徒AIの式・グラフ・性格別発話 |

`simulation_timeline_experiment.ipynb` から開始してください。LLM使用時はColabのGPUを選び、実行結果のモードを確認します。共有用txtは `data/assessments/` に保存します。

## 補助実験

`supplementary/` に旧Notebookを保存しています。

- `student_ai_colab.ipynb`: 生徒AIの詳細評価。
- `personality_experiment.ipynb`: 性格分類。
- `teaching_strategy_experiment.ipynb`: 旧授業戦略実験。
- `paper_core_experiment.ipynb`: 旧論文実験。

補助Notebookもリポジトリルートを作業ディレクトリとして実行します。主実験との結果比較時は条件を合わせてください。
